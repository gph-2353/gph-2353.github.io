This week’s question

Your model makes assumptions; the residuals show where it breaks them.

  • Every lm() you have fit so far came with fine print you signed without reading
  • Weeks 4-5 (t tests, CIs, prediction intervals) all lean on that fine print
  • This week and next: how to read the fine print, and how to catch the model breaking it
  • The informants are the residuals e_i = y_i - \hat y_i: everything the model got wrong, one number per observation

The fine print: the model

y_i = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_p x_{ip} + \varepsilon_i

  • The standard assumptions are all about the errors \varepsilon_i
  • We never see \varepsilon_i. We see the residuals e_i, which estimate them

The fine print: four assumptions on the errors

  1. Mean zero given the predictors: the linear form is right; nothing systematic is left over
  2. Constant variance: the scatter around the line is the same everywhere (\operatorname{Var}(\varepsilon_i) = \sigma^2)
  3. Independence: one observation’s error tells you nothing about another’s
  4. Normality: the errors follow a normal distribution

Rank them: not all violations are equal

Rank Assumption If violated
1 Mean zero (linearity) Estimates aim at the wrong target
2 Constant variance Slopes fine; SEs, CIs, PIs wrong
3 Independence SEs can be badly off
4 Normality Matters least: PIs, small n (Week 7)

Using the ranking

  • The ranking guides your energy: chase curvature first, fans second
  • Independence is mostly a design question (repeated measures? clustered? time-ordered?), not a plot question

Why residuals vs fitted is the workhorse

  • Plot e_i (vertical) against \hat y_i (horizontal)
  • If the model is right, residuals are what is left after removing all structure: the plot should be a boring, structureless blob centered at zero
  • Anything visible (a curve, a fan, a stray point) is structure the model missed
  • One plot works for any number of predictors, because \hat y_i compresses them all onto one axis

The workhorse on a familiar model

The null plot

Train your eyes on what “nothing” looks like. Diagnosing is comparing your plot to boring.

plot(fitted(fit_bp), resid(fit_bp),
     xlab = "Fitted values", ylab = "Residuals",
     main = "bp_sys ~ age (NHANES adults)")

The workhorse on a familiar model

A gallery with known answers

Four simulated datasets, same straight-line model lm(y ~ x) fit to each. I know the truth because I wrote the code. Diagnose each panel.

Code 
set.seed(601)
n <- 120
x <- runif(n, 0, 10)
gallery <- bind_rows(
  tibble(panel = "A", x = x, y = 2 + 0.7 * x + rnorm(n, sd = 0.25 * x)),
  tibble(panel = "B", x = x, y = 2 + 0.7 * x + rnorm(n, sd = 1.2)),
  tibble(panel = "C", x = x, y = 2 + 0.7 * x + c(rnorm(n - 1, sd = 1.2), 9)),
  tibble(panel = "D", x = x,
         y = 2 + 0.7 * x - 0.18 * (x - 5)^2 + rnorm(n, sd = 1.2))
)
gallery_resid <- gallery |>
  group_by(panel) |>
  mutate(fitted = fitted(lm(y ~ x)), resid = resid(lm(y ~ x))) |>
  ungroup()
gallery_plot <- ggplot(gallery_resid, aes(fitted, resid)) +
  geom_point(alpha = 0.6) +
  geom_hline(yintercept = 0, linetype = 2) +
  facet_wrap(~panel, scales = "free") +
  labs(x = "Fitted values", y = "Residuals")

The gallery

Gallery, answered: A and B

  • A: fan. Errors were generated with sd = 0.25 * x: spread grows with the fitted value. Nonconstant variance
  • B: nothing. Honest constant-variance noise. This is what healthy looks like: hold onto it

Gallery, answered: C and D

  • C: one outlier. All errors normal except one observation pushed up by 9 (about 7 standard deviations). One point, far from the band
  • D: curve. The truth includes -0.18(x-5)^2; the straight line misses systematically, so residuals arc: positive, negative, positive

Warning

Real plots whisper; simulations shout. The lab drills you on the same four shapes so you recognize the whisper.

Pattern, problem, consequence

You see It suggests What it costs you
Curve or arc Wrong mean function (nonlinearity) Biased estimates; wrong story
Fan or funnel Nonconstant variance Wrong SEs, CIs, p-values, PIs
Isolated stray point Outlier or data error Can drag the whole fit (Week 7)
Boring blob Nothing detectable Carry on
  • “No visible problem” only rules out problems big enough to see

Residuals vs individual predictors

\hat y compresses all predictors onto one axis, which can hide which predictor is at fault. Plot residuals against each predictor too.

Code 
set.seed(602)
m <- 200
x1 <- runif(m, 0, 10)
x2 <- runif(m, -3, 3)
y <- 1 + x1 + x2^2 + rnorm(m)
fit2 <- lm(y ~ x1 + x2)
sim2 <- tibble(x1, x2, resid = resid(fit2)) |>
  pivot_longer(c(x1, x2), names_to = "predictor", values_to = "value")
sim2_plot <- ggplot(sim2, aes(value, resid)) +
  geom_point(alpha = 0.5) +
  geom_hline(yintercept = 0, linetype = 2) +
  facet_wrap(~predictor, scales = "free_x") +
  labs(x = "Predictor value", y = "Residuals")

Residuals vs individual predictors

  • Truth: y = 1 + x_1 + x_2^2 + \varepsilon. Fine vs x_1; a parabola vs x_2
  • Routine: residuals vs fitted first, then vs each predictor

Think-pair-share (2 min)

A classmate fits uninsured ~ poverty on county data and finds a clear fan: residual spread grows with fitted values.

  1. Which assumption is in question?
  2. Is the estimated slope biased because of this?
  3. Which parts of last week’s output should they distrust?

Fan means assumption 2, not assumption 1: the slope is still an unbiased estimate of the linear association, but its SE, the CIs, and especially the prediction intervals are built on a variance that is not one number.
