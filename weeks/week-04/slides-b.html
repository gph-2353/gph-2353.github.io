Questions a single t-test cannot answer

The t-tests this morning were one coefficient at a time. But we often need:

  • Do the predictors explain anything as a group? (the whole model vs nothing)
  • Does adding a block of terms help? (education enters as four dummy columns; “does education matter” is four coefficients at once)
  • Is the bigger model worth it compared to a smaller one?

All of these are F-tests: comparisons of two nested models.

The overall F-test

H_0: every slope is zero (\beta_{\text{smoker}} = \beta_{\text{age}} = 0); the model is no better than predicting \bar y for everyone.

summary(fit)$fstatistic
   value    numdf    dendf 
 267.135    2.000 2085.000
  • Bottom line of summary(): F = 267.1 on 2 and 2085 df, p < 2.2e-16
  • F compares explained variation per predictor to leftover variation per residual df; big F means the model explains far more than chance would
  • Almost always rejected in practice; a model that fails this test is in serious trouble

Nested models: does education improve the model?

education has 5 levels, so it enters as 4 dummy columns. One question, four coefficients: a job for anova().

d_ed <- nhanes_adults |> drop_na(bp_sys, age, smoker, education)
m_small <- lm(bp_sys ~ smoker + age, data = d_ed)
m_big   <- lm(bp_sys ~ smoker + age + education, data = d_ed)
anova(m_small, m_big)
Analysis of Variance Table

Model 1: bp_sys ~ smoker + age
Model 2: bp_sys ~ smoker + age + education
  Res.Df    RSS Df Sum of Sq      F   Pr(>F)   
1   2085 520704

Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
  • One p-value (0.0036) for the whole education block: education improves the model beyond smoking and age
  • Never read four separate dummy t-tests to decide this; they only compare each level to the reference level

Anatomy of that ANOVA table

Column Meaning
Res.Df residual degrees of freedom of each model
RSS residual sum of squares: unexplained variation
Df 4: how many coefficients the big model adds
Sum of Sq 3887: the RSS drop the new terms bought
F (RSS drop / 4) divided by (big model RSS / its Res.Df)
Pr(>F) how surprising that F is if the new terms are all zero
  • Nesting requirement: the small model’s terms are a subset of the big model’s, fit to the same rows (that is why we built d_ed first)

t and F are the same test for one coefficient

Drop a single term and the F-test reproduces the t-test exactly:

m0 <- lm(bp_sys ~ age, data = d)
anova(m0, fit)
Analysis of Variance Table

Model 1: bp_sys ~ age
Model 2: bp_sys ~ smoker + age
  Res.Df    RSS Df Sum of Sq      F  Pr(>F)  
1   2086 522139                              
2   2085 520704  1    1434.8 5.7454 0.01662 *
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
c(t = summary(fit)$coefficients["smokerSmoker", "t value"],
  t_squared = summary(fit)$coefficients["smokerSmoker", "t value"]^2)
        t t_squared 
 2.396947  5.745353
  • t^2 = 2.397^2 = 5.75 = F, and the p-values match (0.0166)
  • The t-test is the 1-df special case of the F-test; one machine, two dials

What anova() cannot do

  • Non-nested models: bp_sys ~ age + bmi vs bp_sys ~ age + income_mid. Neither contains the other; there is no “RSS drop from added terms” logic, so no F-test exists
  • Try it and R tells you so: fit to the same rows, the table comes back with Df = 0 and no F, no p-value; fit to different rows (income has missing values), anova() refuses outright
  • Comparing non-nested models needs different tools (AIC/BIC, validation): Week 10

The discipline

Before you run anova(m1, m2), say out loud which terms the big model adds and confirm both models use the same rows. If you cannot, the test is not answering your question.

Statistical vs practical significance

With n around 2000, tiny associations clear the p < 0.05 bar:

dc <- nhanes_adults |> drop_na(bp_sys, age, alcohol_days)
summary(lm(bp_sys ~ age + alcohol_days, data = dc))$coefficients
                 Estimate  Std. Error   t value     Pr(>|t|)
(Intercept)  101.52529297 1.102571963 92.080423 0.000000e+00
age            0.40694268 0.021585803 18.852330 4.764758e-72
alcohol_days   0.01519723 0.003716554  4.089065 4.536485e-05
  • Each additional drinking day per year: 0.015 mmHg higher average BP, p = 4.5e-5
  • Hugely “significant,” clinically invisible: 100 extra drinking days a year predicts a 1.5 mmHg difference
  • p-values measure evidence against “exactly zero,” not importance. NHANES is big; national surveys and EHR studies are far bigger. Report the estimate and CI, then judge the size

Lab part B (pairs): pre-registered inference

Real studies state the hypothesis before looking. You will too:

  1. Write H_0 and H_1 about some NHANES association, plus your adjustment set, before fitting anything
  2. Fit exactly the pre-registered model; no peeking and swapping
  3. Report the result journal-style: estimate, 95% CI, p-value, one honest caveat
  4. The result you get is the result you report, significant or not; exit ticket as usual
