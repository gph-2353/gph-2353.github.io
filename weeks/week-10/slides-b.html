Selection on our county data

Outcome: uninsured. Nine socioeconomic candidates:

ch <- county_health |>
  drop_na(uninsured, poverty, median_income, per_capita_income,
          unemployment, bachelors, hs_grad, median_age, broadband, density)
full <- lm(uninsured ~ poverty + median_income + per_capita_income +
             unemployment + bachelors + hs_grad + median_age +
             broadband + density, data = ch)
nrow(ch)
[1] 1266
  • drop_na() first: step() needs every model fit to the same rows; poverty alone is missing for 1,876 counties
  • Complete cases: 1,266 of 3,142 counties. That loss is itself a modeling decision worth reporting

AIC vs BIC: what each picks

sel_aic <- step(full, direction = "backward", trace = 0)
sel_bic <- step(full, direction = "backward", k = log(nrow(ch)), trace = 0)
formula(sel_aic)
uninsured ~ poverty + median_income + bachelors + hs_grad + median_age + 
    broadband + density
formula(sel_bic)
uninsured ~ poverty + median_income + bachelors + hs_grad + median_age + 
    broadband
  • Both criteria discard unemployment and per_capita_income
  • The disagreement is one variable: AIC keeps density, BIC (penalty \log 1266 \approx 7.1, steep at this n) drops it
  • density has p = 0.012 under AIC: useful, not overwhelming

Breaking the tie

  • Adjusted R^2 differs in the third decimal (0.415 vs 0.413). Either model tells essentially the same story
  • When criteria disagree this mildly, interpretability and your scientific question should break the tie, not the decimals

Cautions about model selection

  • Selection invalidates naive p-values. The p-values in summary(sel_bic) are computed as if this model were chosen before seeing the data. It was not: the data picked it, so those p-values and CIs are too optimistic
  • There is a field called post-selection inference that corrects this; it is beyond this course

An honest selection workflow

  • In this course, the honest workflow is:
    1. Choose honestly: decide the candidate set from subject knowledge before fitting
    2. Validate if you can: refit the selected model on held-out data, or at least check it on a random half
    3. Report what you tried: “we ran backward BIC starting from these nine candidates” beats silence

For your project

A good Methods section: data and model

Four short paragraphs, written so a classmate could rerun your analysis:

  1. Data: source, unit of observation, n, how missing values were handled
  2. Model: the final model stated as a formula, outcome units, any transformations and why

Methods section: selection and checking

  1. Selection: candidate predictors, how you chose among them (subject knowledge first, criterion second), and what you tried that did not survive
  2. Checking: which diagnostics you ran and what you did about problems

The most common Methods failure: describing only the final model, as if it arrived by revelation. Show the path.
