Two different jobs for the same lm()

Weeks 3-4: explanation. Which predictors matter, how big is the adjusted association, is it real?

This week: prediction. Given a county’s characteristics, what uninsured rate should we expect, and how sure are we?

  • Same fitted model, different questions, different loyalties
  • Explanation obsesses over one coefficient’s meaning; prediction obsesses over \hat y and its error bars
  • A model can be excellent at one job and poor at the other

This week’s question

How well can we predict a county’s uninsured rate, and how sure are we?

New dataset, new scale: county_health (ACS 2019, via the usdata package).

The model, and predict() with newdata

m <- lm(uninsured ~ poverty + unemployment + median_age, data = ch)
coef(m)
 (Intercept)      poverty unemployment   median_age 
   8.6798723    0.2861535    0.0349146   -0.1061795 
new_county <- tibble(poverty = 15, unemployment = 5, median_age = 40)
predict(m, newdata = new_county)
       1 
8.899566
  • predict() plugs the new predictor values into the fitted equation: expected uninsured rate about 8.9% for this profile
  • newdata must contain every predictor, with the same names
  • A point prediction with no error bars is a half-answer. There are two very different full answers…

Two questions, two intervals

Question 1 (mean response): among all counties with poverty 15%, unemployment 5%, median age 40, what is the average uninsured rate?

Question 2 (single county): this particular new county has that profile. What is its uninsured rate?

  • Q1 needs a confidence interval: uncertainty about where the regression surface sits (only estimation wobble in \hat\beta)
  • Q2 needs a prediction interval: surface wobble plus the county-to-county scatter around the surface (\sigma, estimated at 3.9 points)
  • Conceptually: SE_{CI}^2 reflects \widehat{Var}(\hat y) alone, while SE_{PI}^2 = \widehat{Var}(\hat y) + \hat\sigma^2. The PI is always wider

Both, from the same function

predict(m, newdata = new_county, interval = "confidence")
       fit      lwr      upr
1 8.899566 8.678986 9.120147
predict(m, newdata = new_county, interval = "prediction")
       fit      lwr      upr
1 8.899566 1.218996 16.58014
  • CI: the average uninsured rate for counties like this is between 8.7 and 9.1%. Tight, because n = 1,266 pins down the surface well
  • PI: this one county could plausibly be anywhere from about 1 to 17%. Wide, because counties with identical poverty, unemployment, and age still differ enormously (state policy, immigration, labor markets…)
  • More data shrinks the CI toward zero width; the PI can never shrink below the residual scatter

Seeing both bands

Code 
m1 <- lm(uninsured ~ poverty, data = ch)
grid <- tibble(poverty = seq(min(ch$poverty), max(ch$poverty), length.out = 200))
bands <- bind_cols(
  grid,
  as_tibble(predict(m1, grid, interval = "confidence")) |> rename(ci_lo = lwr, ci_hi = upr),
  as_tibble(predict(m1, grid, interval = "prediction")) |> select(pi_lo = lwr, pi_hi = upr)
)
ggplot(ch, aes(poverty, uninsured)) +
  geom_point(alpha = 0.2) +
  geom_ribbon(data = bands, aes(y = fit, ymin = pi_lo, ymax = pi_hi), fill = "steelblue", alpha = 0.2) +
  geom_ribbon(data = bands, aes(y = fit, ymin = ci_lo, ymax = ci_hi), fill = "steelblue", alpha = 0.5) +
  geom_line(data = bands, aes(y = fit), color = "steelblue") +
  labs(x = "Poverty rate (%)", y = "Uninsured (%)")
  • Inner band: CI for the mean, hugging the line. Outer band: PI, built to catch about 95% of individual counties (here it catches about 95%, a good sign)
  • Both flare at the edges: predictions are least certain where data are thin
