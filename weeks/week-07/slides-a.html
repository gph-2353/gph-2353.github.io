The Q-Q plot

To check normality, compare the sorted residuals to where sorted values should fall if they were normal.

  • Plot the i-th smallest residual against the normal quantile \Phi^{-1}\!\left(\frac{i}{n+1}\right)
  • If residuals are normal: points hug a straight line
  • Departures have signatures: tails that peel off, curves that bend one way

The Q-Q plot for our BP model

qqnorm(resid(fit_bp)); qqline(resid(fit_bp))
  • Middle is straight, upper tail peels upward. Keep that in mind

Q-Q gallery with known truth

Four simulated samples; I wrote the generator, so the diagnosis is certain.

The Q-Q gallery

Reading the gallery

  • Normal, n = 200: hugs the line; this is your reference for boring
  • Heavy tails: both ends peel away (low end too low, high end too high); the most consequential departure, it breaks prediction intervals
  • Right skew: curved like a smile; short lower tail, long upper tail; common for costs, counts, rates
  • Normal, n = 25: genuinely normal, yet the ends wobble; small samples always look a bit ragged, so do not over-read tails at small n

Shapiro-Wilk: the formal test

shapiro.test(resid(fit_bp))

    Shapiro-Wilk normality test

data:  resid(fit_bp)
W = 0.96701, p-value < 2.2e-16
  • W = 0.967, p = 1.8 \times 10^{-21}: overwhelming rejection for our BP model
  • So is the model ruined? The Q-Q plot showed a moderate right skew and n = 2,088. Hold that thought

Normality tests mislead at large n

set.seed(2026)
close_to_normal <- rt(5000, df = 15)   # nearly normal
clearly_heavy  <- rt(30, df = 3)       # genuinely heavy-tailed
c(big_n_p = shapiro.test(close_to_normal)$p.value,
  small_n_p = shapiro.test(clearly_heavy)$p.value)
     big_n_p    small_n_p 
5.205110e-07 1.412366e-01
  • t_{15}, n = 5,000: looks just like a normal, yet p \approx 5 \times 10^{-7}: rejected
  • t_3, n = 30: the tails that wreck prediction intervals, yet p \approx 0.14: waved through
  • The test rejects when it matters least and passes when it matters most; the Q-Q plot gets the final word

When normality actually matters

Situation How much normality matters
Prediction intervals (any n) A lot: PIs use the error tails
CIs and t tests, small n Considerably
CIs and t tests, large n Barely: the CLT rescues \hat\beta
Point estimates Not at all for unbiasedness
  • Our BP model (n = 2,088): age-slope CIs are trustworthy despite Shapiro; individual PIs inherit the skew

Correlated errors

Assumption 3: knowing one error tells you nothing about another. Violated by time order (this month resembles last month), clusters (counties in the same state), repeated measures (same person twice).

Code 
set.seed(2026)
n <- 60
t_idx <- 1:n
e <- as.numeric(arima.sim(list(ar = 0.7), n = n, sd = 2))
y <- 50 + 0.3 * t_idx + e   # e.g., a monthly clinic caseload with a trend
fit_t <- lm(y ~ t_idx)
plot(t_idx, resid(fit_t), type = "b",
     xlab = "Time order", ylab = "Residuals")
abline(h = 0, lty = 2)

Residuals in time order

  • Slow waves: neighboring months are alike
  • Each month adds less information than the SE assumes

Durbin-Watson, briefly

car::durbinWatsonTest(fit_t)
 lag Autocorrelation D-W Statistic p-value
   1       0.6658386      0.561717       0
 Alternative hypothesis: rho != 0
  • The Durbin-Watson statistic near 2 means no serial correlation; here it is about 0.56 with estimated autocorrelation 0.67: strong
  • Know the name and the plot (residuals vs time order); details belong to a time series course
  • Our data are cross-sectional: serial correlation rarely arises. The quieter cousin, clustering (counties in a state share policy), is beyond this course: acknowledge it in write-ups
