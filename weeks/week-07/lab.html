Part A: Influence walkthrough on savings (11:40-12:10)

The savings data: average savings rate (sr, % of disposable income) for 50 countries, 1960-1970, with age structure (pop15, pop75), per-capita disposable income (dpi), and income growth (ddpi). Country names are the row names. This is the most famous influence example in the regression literature; by the end you will know why.

A2. Leverage: who has unusual predictors?

Leverage (hat value) h_i measures how extreme country i’s predictor profile is. The average must be p/n; values above 2p/n deserve a look.

h <- hatvalues(g)

n <- ___          # number of countries
p <- ___          # number of coefficients (count the intercept!)
c(average_leverage = p / n, flag_threshold = 2 * p / n)

sort(h, decreasing = TRUE)[1:5]
halfnorm(h, labs = row.names(savings), ylab = "Leverage")

Which two countries exceed the threshold? For the top one, look at its row (savings["___", ]) and compare to summary(savings$ddpi): which predictor makes it extreme? …

A3. Outliers: who has a surprising savings rate?

Studentized residuals re-estimate the error SD without each observation, so a big outlier cannot dilute its own evidence. With 50 countries we examine the biggest of 50 residuals, so we use the Bonferroni-corrected cutoff.

rst <- rstudent(g)
sort(abs(rst), decreasing = TRUE)[1:3]

qt(1 - 0.05 / (2 * n), df = n - p - 1)   # Bonferroni critical value

Which country has the largest studentized residual, and is it a formal outlier by the Bonferroni standard? One sentence. …

Part B: The pathology hunt (12:50-13:25, in pairs)

Each of the four variants below draws a fresh sample of 50 counties and (in three of the four) plants exactly one anomaly in row 50. One variant is completely clean. You get one variant; you do not know in advance which kind you drew.

Run this chunk as-is, then set your variant from your pair number.

make_variant <- function(variant) {
  stopifnot(variant %in% 0:3)
  pool <- county_health |>
    drop_na(uninsured, poverty) |>
    filter(between(poverty, 5, 22), between(uninsured, 3, 22))
  seeds <- c(69, 3, 7, 13)
  set.seed(seeds[variant + 1])
  d <- pool |> slice_sample(n = 50) |> select(state, name, uninsured, poverty)
  if (variant == 1) { d$poverty[50] <- 45; d$uninsured[50] <- 19.75 }
  if (variant == 2) { d$uninsured[50] <- d$uninsured[50] + 22 }
  if (variant == 3) { d$poverty[50] <- 50; d$uninsured[50] <- 2 }
  d
}
